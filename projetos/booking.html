Service Booking

Interface web de um MicroSaaS de agendamento focado em estética e beleza.

Código

Plataforma SaaS desenvolvida em PHP puro estruturada com boas práticas de organização, utilizando Programação Orientada a Objetos para a gestão da base de dados, com uma área pública para clientes e um painel administrativo protegido para gestão.

Tecnologias

  • - PHP
  • - MySQL
  • - HTML
  • - CSS

Estrutura de arquivos


    saas/
├── admin/                    # Painel Administrativo
│   ├── index.php             # Página de login do painel
│   ├── layout/
│   │   └── sidebar.php       # Componente da barra lateral e topbar (com nome dinâmico)
│   └── login/
│       ├── login.php         # Lógica de autenticação e sessões
│       └── logout.php        # Encerramento de sessão
├── public/                   # Recursos estáticos acessíveis publicamente
│   └── css/                  # Folhas de estilo CSS modularizadas (login.css, services.css, etc.)
└── src/                      # Código-fonte backend e lógica da aplicação
    ├── Config/
    │   └── Database.php      # Classe de conexão PDO com a base de dados
    ├── Controller/           # Controladores do sistema
    ├── DAO/                  # Objetos de Acesso a Dados (ProfissionalDAO, ServicoDAO, etc.)
    ├── Layouts/              # Layouts e templates globais do sistema
    └── Model/                # Classes de Modelo (Agendamento, Profissional, Servico, etc.)
