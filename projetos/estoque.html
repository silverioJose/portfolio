Estoque

Aplicação desktop em JavaFX + SQLite para controlar o estoque da casa e gerar a lista de compras.

Funcionalidades

  • - Cadastro de produtos com departamento, unidade e estoque mínimo
  • - Tela inicial com carrossel de produtos e filtro por departamento
  • - Alerta de produtos com estoque baixo
  • - Cadastro rápido de produto via modal

Em desenvolvimento

  • - Histórico de movimentações
  • - Detalhes do produto
  • - Geração da lista de compras

Tecnologias

  • - Java
  • - JavaFX (FXML + CSS)
  • - SQLite
